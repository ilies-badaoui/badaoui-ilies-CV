# Portfolio — Ilies Badaoui

Portfolio personnel d'Ilies Badaoui, Concepteur Développeur d'Application.

Site statique en HTML/CSS/JS pur (aucune dépendance, aucun build), pensé pour être hébergé
gratuitement sur GitHub Pages.

## Aperçu local

Ouvrez simplement `index.html` dans un navigateur, ou lancez un petit serveur local :

```bash
python -m http.server 8000
```

puis ouvrez `http://localhost:8000`.

## Déploiement sur GitHub Pages

1. Créez un dépôt GitHub (par ex. `portfolio` ou `<votre-pseudo>.github.io`).
2. Poussez ce dossier dessus.
3. Dans les paramètres du dépôt : **Settings → Pages → Branch: main → /(root)**.
4. Le site sera disponible à `https://<votre-pseudo>.github.io/<nom-du-repo>/`
   (ou directement à `https://<votre-pseudo>.github.io/` si le dépôt s'appelle `<votre-pseudo>.github.io`).

## À personnaliser

- Les liens GitHub / LinkedIn dans `index.html` (section `#contact`) sont des placeholders — à remplacer par vos vrais profils.
- Ajoutez vos projets si vous le souhaitez (une section `#projets` peut être ajoutée facilement en suivant la structure des autres sections).
