API France

Tapez une adresse française : les suggestions, le code postal et la ville se remplissent automatiquement grâce à l'API officielle Base Adresse Nationale (data.gouv.fr).

API REST Autocomplétion Debounce

À propos de cette version

  • Version originale : jQuery UI Autocomplete sur 3 champs séparés (adresse/CP/ville), chacun relançant sa propre recherche.
  • Amélioré ici : vanilla JS avec debounce (pas de requête à chaque frappe), un seul champ de recherche qui remplit CP et ville, résultat détaillé (coordonnées, score de pertinence).
  • API utilisée : Base Adresse Nationale, gratuite et sans clé.
